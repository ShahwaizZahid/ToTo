# 🍔 TOTO (Top Of The Order) - Food Delivery App

TOTO is a modern, responsive food delivery application built with **Flutter**. The app allows users to browse food items, add them to the cart with customizations, view detailed receipts, and track delivery progress — all with light/dark mode and persistent login using `SharedPreferences`.

---

## 🚀 Features

- 🔐 **User Authentication**

  - Register & Login functionality
  - Session managed with SharedPreferences

- 🛒 **Cart System**

  - Add items with count and add-ons
  - Cart data fetched dynamically using HTTP

- 📄 **Receipt Generator**

  - Auto-generated receipt with items, price, add-ons, and estimated delivery time

- 🚚 **Delivery Progress Page**

  - Shows order delivery and driver contact options

- 🎨 **Theme Switching**

  - Toggle between Light and Dark modes
  - Theme persisted using SharedPreferences

- 📱 **Responsive UI**

  - Clean, modern, and mobile-optimized design
  - Cupertino switches and Material buttons combined

- 📖 **Help & About Pages**
  - User guidance and contact info
